PM can do this

1 fix

Make these changes only after the merchant approves. If a label looks different, stop and ask your agency lead.

F1. VIP automatic discount · fixes S1.R1 · P1

  1. Customers > Segments: create a segment for customers tagged VIP.
  2. Discounts > Create discount > Amount off products > Automatic.
  3. 15%, all products except gift cards; eligibility: the VIP segment.
  4. Combinations: match what the merchant wants (see W1).

Check it worked: run T1. How close to the old Script: close. Shoppers now see a discount line instead of a lower price.
