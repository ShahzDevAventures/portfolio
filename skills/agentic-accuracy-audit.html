AgenticAccuracy Audit

Every Shopify store now publishes a file and a set of tools for AI shopping agents. This audit checks whether what those agents are told about products, prices, discounts and policies matches the website.

The problem

A shopper asks an AI agent what a product costs and gets the full price, because the sale only exists in the theme or at the cart. In the first test run, three of a store's four best sellers showed a bundle saving on the product page that every agent tool missed.

Ask the store what agents ask, then check every answer against the site.

Claude works in the PM's own Chrome, calls only the store's read-only agent tools, and compares each answer with the page a shopper would see.

  1. Find the agent surfaces. The store's agents.md file, its UCP profile, the store's agent API, the tools built into its web pages, and Shopify Catalog, which feeds ChatGPT, Copilot and Shop.
  2. Check catalog coverage. Which products agents can find, which are missing, and which are expected exclusions such as gift cards and helper products.
  3. Compare a fixed sample. Four best sellers, up to three promoted products and the rest spread across the catalog: price, crossed-out price, stock and options, on both sides.
  4. List every promotion. Banners, product-page offers and admin discounts, each marked as visible to agents in the price, as text, or not at all.
  5. Question the store's own agent. Fifteen fixed questions on returns, shipping, promotions and more, each graded against the store's policy pages.
  6. Hand over what needs a cart. Whether a cart discount really applies is written up as a manual checklist. Claude never adds to cart.

One report per store, with the answer first.

A single HTML file styled like the Shopify admin, plus a Markdown copy for tickets. Top fixes come first, split between what the PM can change in the admin and what needs a developer.

  • Top fixes ranked by severity, with who fixes each one
  • What agents can see: each surface and its status
  • Product comparison for the fixed sample
  • Promotions and discounts and whether agents can see them
  • Agent answers vs the website, question by question
  • Manual checklist for anything that needs a cart

Install it

Install it in the Claude app and connect Claude in Chrome. With admin access it runs all 22 checks; without it, it runs a public-only audit and says which checks it skipped.

Claude app

  1. Download the skill file below.
  2. In Claude, open Settings → Capabilities and turn on Code execution and file creation.
  3. Open Customize → Skills, click +, then Create skill → Upload a skill, and choose the file.
  4. Install the Claude in Chrome extension and connect it. Without it, the skill walks you through a manual export instead.
  5. Open the store in Chrome (signed in to the admin if you have access), then start a new chat.
Download agentic-accuracy-audit.zip

Claude Code

Run this once in a terminal:

npx skills add ShahzDevAventures/agentic-accuracy-audit

Then start Claude Code in any folder and ask for the audit.

Then say: Run the agentic accuracy audit for example-store.com
