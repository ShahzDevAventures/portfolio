The problem

When Shopify switched Scripts off, checkout kept running. The VIP discount, the hidden shipping rate and the payment rule each stopped without an error. An agency with 30 Plus stores had no quick way to see which stores lost what.

Find every Script, work out what it did, check what replaced it.

Claude reads the store admin in the PM's own Chrome and only looks. Without Chrome, it walks the PM through exporting the Scripts report and copying a few pages.

  1. Find the right store. The admin handle is read from the store switcher, never guessed from the website address. On one real client the two were completely different.
  2. Check there is anything to migrate. If the store never had Scripts, the PM gets a one-page "nothing to migrate" report and the run stops.
  3. Read each Script as rules. Every condition and effect becomes a rule with who it affected, what it did, when, and the message shoppers saw. Drafts that never ran are marked as such.
  4. Check what is live today. Discounts, rollouts, shipping, payments, checkout rules and installed apps are compared with each rule: lost, replaced, partly replaced, or never ran.
  5. Pick the fix. A native setting with click-by-click steps the PM can follow, or a written spec for a custom Shopify Function. Anything that can't be reproduced exactly is listed as a gap with the closest option.
  6. Rank and test. Lost rules are ranked by revenue impact, and every rule gets a plain-English test checkout the PM runs up to the payment step.

One report per store, with the answer first.

A single HTML file styled like the Shopify admin, plus a Markdown copy for tickets. The summary and this week's fixes read in five minutes. Evidence, developer specs and the original code are folded underneath.

  • Priority list: what shoppers lost, ranked by revenue impact
  • Script-by-script findings with a status and the evidence behind it
  • PM can do this: native settings, click by click
  • Needs a developer: Function specs with inputs, logic and edge cases, and no code
  • Test-checkout checklist with the expected result for each test
  • Things the PM must check for anything the audit couldn't see

Install it

Install it in the Claude app and connect Claude in Chrome. The PM needs a staff or collaborator login for the store, already signed in. Claude never signs in or asks for a password.

Claude app

  1. Download the skill file below.
  2. In Claude, open Settings → Capabilities and turn on Code execution and file creation.
  3. Open Customize → Skills, click +, then Create skill → Upload a skill, and choose the file.
  4. Install the Claude in Chrome extension and connect it. Without it, the skill walks you through a manual export instead.
  5. Sign in to the store's Shopify admin in Chrome, then start a new chat.
Download scripts-to-functions-audit.zip

Claude Code

Run this once in a terminal:

npx skills add ShahzDevAventures/scripts-to-functions-audit

Then start Claude Code in any folder and ask for the audit.

Then say: Run the Scripts to Functions audit for example-store.com
