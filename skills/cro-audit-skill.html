The problem

Most CRO audits are a tour of the site: homepage first, footer last, every issue the same size. The merchant can't tell which fix pays for the audit.

Check the expensive failures first, then work down the store in revenue order.

The method comes from Shopify Plus engagements at Sirge, written down so it runs the same way every time.

  1. Find the brand. Before fetching anything, it confirms the right store, its category and its competitors.
  2. Run the six-point check. Catastrophic page speed, a hero that doesn't say what's for sale, feature-first copy, a broken path to checkout, too many choices, and social proof that's buried or unproven.
  3. Review five areas in priority order. Mobile, product discovery, homepage, product pages, then cart and checkout.
  4. Fall back when nothing fires. If the six checks come back clean, it looks at competitive positioning, revenue leakage, buyer psychology and retention instead.
  5. Rank by revenue. Anything that stops pages loading comes first, then conversion rate, then order value, then repeat purchases. Speed numbers come from PageSpeed Insights or are marked not checked.

An audit ordered by impact, not by page.

One HTML file styled like the Shopify admin. No code, mockups or wireframes, and anything it could not see from public pages is listed as not checked.

  • Executive summary: where the store is losing sales, with issue counts
  • Priority issues in impact order, each with evidence, the fix, an A/B test and how to measure it
  • Industry benchmarks from competitors checked live
  • Testing roadmap for weeks 1 to 2, 3 to 6 and 7 to 12
  • This week: the actions to take before anything else
  • What we could not check, and how to fill each gap

Install it

It works in the Claude app or Claude Code. It reads the store's public pages, so no store login is needed.

Claude app

  1. Download the skill file below.
  2. In Claude, open Settings → Capabilities and turn on Code execution and file creation.
  3. Open Customize → Skills, click +, then Create skill → Upload a skill, and choose the file.
  4. Start a new chat.
Download cro-audit-skill.zip

Claude Code

Run this once in a terminal:

npx skills add ShahzDevAventures/cro-audit-skill

Then start Claude Code in any folder and ask for the audit.

Then say: Run a CRO audit for example-store.com
