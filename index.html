Four Shopify audits, open source.

Built for agency project managers rather than developers. Each skill reads one store, changes nothing, and hands back a report the merchant can act on. Install one in the Claude app by uploading a single file, or in Claude Code with one command.

scripts-to-functions-audit

Shopify switched Scripts off on June 30, 2026, and checkout kept running without them. This audit finds what each script did, what the store has been missing since, and how to restore it: a native setting the PM can change, or a written spec for a custom Function.

npx skills add ShahzDevAventures/scripts-to-functions-audit
How it works → GitHub →
agentic-accuracy-audit

Every Shopify store now publishes a file and a set of tools for AI shopping agents. This audit checks what those agents are told about products, prices, discounts and policies against what a shopper sees on the site, and lists every mismatch.

npx skills add ShahzDevAventures/agentic-accuracy-audit
How it works → GitHub →
shopify-seo-audit

Turns a store URL, plus a Search Console export when there is one, into a ranked SEO fix list, split into theme fixes for a developer and admin fixes for the merchant.

cro-audit-skill

A conversion audit for Shopify stores. It checks the common failures first, then the homepage, product pages, cart, discovery and mobile, and ranks every finding by its likely revenue impact.
